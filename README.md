Real-Time Chat Application

This is a real-time chat application built using Node.js, Express, and Socket.io. It allows users to join a chatroom, send messages, and see a list of active users. The server is designed to run locally or on a platform like Render.

Features

Real-time messaging using WebSockets (Socket.io)

User join and disconnect notifications

Active users list

Responsive front-end using static files served by Express

Prerequisites

Ensure you have the following installed:

Node.js (LTS recommended)

npm (comes with Node.js)
